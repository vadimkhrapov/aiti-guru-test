# aiti-guru-test

## Запуск проекта

### Требования

- **Node.js** 18+ (рекомендуется 20+)
- **pnpm** (рекомендуется) или npm / yarn

### Установка и запуск

```bash
# Клонировать репозиторий
git clone <url-репозитория>
cd aiti-guru-test

# Установить зависимости (pnpm)
pnpm install

# Запустить dev-сервер
pnpm dev
```

Приложение откроется по адресу: **http://localhost:5173**

### Альтернативные команды

```bash
# Сборка для production
pnpm build

# Предпросмотр production-сборки
pnpm preview

# Линтинг
pnpm lint

# Форматирование кода
pnpm format
pnpm format:check
```

## О проекте

Веб-приложение для управления каталогом товаров с авторизацией. Реализовано на React 19, TypeScript и Vite.

### Основные возможности

- **Авторизация** — вход через логин/пароль (API DummyJSON)
- **Каталог товаров** — таблица с поиском, сортировкой и пагинацией
- **Добавление товара** — модальное окно для создания нового товара (локально)
- **Защищённые маршруты** — доступ к товарам только после входа

### Технологический стек

| Категория | Технологии |
|-----------|------------|
| Фреймворк | React 19, TypeScript |
| Сборка | Vite 8 |
| UI | Ant Design 6 |
| Состояние | Zustand (auth), TanStack React Query (данные) |
| Маршрутизация | React Router 7 |
| HTTP | Axios |

### Архитектура (Feature-Sliced Design)

```
src/
├── app/           # Инициализация приложения, роутер, глобальный store
├── pages/         # Страницы (Login, Products)
├── features/      # Фичи (auth, product-list)
├── entities/      # Бизнес-сущности (user, product)
├── shared/        # Общие модули (API, утилиты)
└── assets/        # Статические ресурсы
```

### API

Приложение использует **DummyJSON API** (`https://dummyjson.com`):

- `POST /auth/login` — авторизация
- `GET /products` — список товаров (с пагинацией и сортировкой)
- `GET /products/search?q=...` — поиск товаров

### Тестовые данные для входа

Для входа можно использовать любые учётные данные из [DummyJSON Users](https://dummyjson.com/users), например:

- **Логин:** `emilys`  
- **Пароль:** `emilyspass`

### Маршруты

| Путь | Описание | Доступ |
|------|----------|--------|
| `/login` | Страница входа | Только для гостей |
| `/` | Каталог товаров | Только для авторизованных |
| `/register` | Регистрация | В разработке |

### Хранение сессии

- **«Запомнить меня»** — данные сохраняются в `localStorage`
- Без галочки — данные в `sessionStorage` (до закрытия вкладки)
